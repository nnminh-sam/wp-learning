# Intake: System Design for Interviews

## Goal
Prepare and learn system design for job interviews at junior to mid level. Start with a quiz as a mock interview to get a general overview of current knowledge. Main role: full-stack software engineer (React, Next.js, Node.js, NestJS).

## Purpose
Interview

## Level
Beginner (self-rated)

## Time
10+ hours/week. Deadline: 1-3 months (target interview date).

## What I already know
Basic knowledge in DB: indexing for improving search query, caching to reduce backend load, JWT authentication, scaling DB via sharding, general knowledge about HTTP request flow, WebSocket for real-time, REST API design principles, ACID in DB, MongoDB, basic ReactJS/NestJS.

## Why now
Preparing for job interviews. "I'm afraid of specific programming language/framework/library questions over system design questions. It gets me down when thinking about interviews a lot."
